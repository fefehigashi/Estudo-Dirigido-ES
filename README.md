# Protótipo - Aplicativo de Estacionamento

Protótipo executável via linha de comando baseado nas necessidades de estacionamento do campus. 
Ele garante a visualização de vagas e evita atritos no login.

**Requisitos Cobertos:**
1. Visualização de vagas em tempo real (REQ-01).
2. Restrição de vagas exclusivas para funcionários na biblioteca (REQ-02).
3. Acesso veloz mediante cache de credenciais para não prender o motorista (REQ-03).

**Como executar:**
Em seu terminal, navegue até a pasta do projeto e digite:
`python main.py`
